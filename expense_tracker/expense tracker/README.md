# Expense Tracker

Локальное веб-приложение для учета, анализа и планирования личных расходов.

## Возможности

- добавление, редактирование и удаление расходов;
- фильтрация по периоду, категории, поиску и диапазону суммы;
- анализ общей суммы, среднего расхода и распределения по категориям;
- график расходов по календарным дням;
- месячный бюджет и прогноз расходов;
- сравнение выбранного месяца с предыдущим;
- получение курсов USD, EUR и CNY к RUB через Frankfurter API;
- сохранение использованного курса вместе с каждой операцией;
- локальный кэш курсов;
- экспорт текущей выборки в CSV;
- автоматические тесты.

## Запуск

Требуется Python 3.11 или новее. Сторонние пакеты не нужны.

```bash
python app.py
```

Откройте в браузере: http://127.0.0.1:8000

## Тесты

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

## Структура

```text
app.py
models/        модель расхода
services/      бизнес-логика и внешний API
storage/       локальное JSON-хранилище
templates/     HTML-интерфейс
static/        CSS и JavaScript
data/          пользовательские данные и кэш
tests/         автоматические тесты
```

## Хранение данных

Расходы хранятся в `data/expenses.json`, настройки бюджета — в `data/settings.json`,
а полученные курсы валют — в `data/rates.json`.

## Внешний источник

Для получения курсов валют используется Frankfurter API. Если внешний сервис
временно недоступен, приложение обрабатывает ошибку без аварийного завершения и
при наличии сохраненного курса может использовать локальный кэш.
